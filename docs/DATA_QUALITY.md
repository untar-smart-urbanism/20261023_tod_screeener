# Data-quality assessment

Eight questions before you trust a dataset. Each row has the test that was run and its result.
Write **unknown** when a dimension cannot be assessed — an honest gap is better than an implied pass.
Quality is relative to purpose: a 1:50,000 layer is fine for regional planning and inadequate for a parcel acquisition.

## Sample properties (`data/sample/properties.geojson`) — SYNTHETIC

| Dimension | Question | Test | Result |
|---|---|---|---|
| Accuracy | Are values and positions correct? | Compare 10 random records with imagery or a site visit | Not applicable — synthetic points |
| Completeness | What is missing, and where? | Null count per field (`npm run inspect`) | 22 of 25 asking prices present (88%); all other fields complete |
| Currency | Recent enough for the decision? | Min/max `listing_date` | 2026-01-12 … 2026-09-13 |
| Consistency | Same units, codes, formats? | Units in field names; type categories; duplicate IDs/positions | m² and IDR throughout; 5 type categories; no duplicate IDs or positions |
| Granularity | Is the unit fine enough? | Point vs parcel vs kelurahan | One point per listing; no parcel boundaries |
| Lineage | Where from, what was done? | Transformations in method log | Generated by course team; no transformations |
| Licensing | May you use, store, share? | Licence recorded; attribution | Teaching use only |
| Bias | Who or what is under-represented? | Coverage across districts and housing types | unknown — synthetic sample |

## Property-data cautions (check each for listings data)
- **Listing ≠ transaction** — label every price "asking"; never call it market value.
- **Duplicates** — one unit, several agents, re-listings: de-duplicate by location + area + type; keep price history.
- **Stale inventory** — filter by listing/update date; record the retrieval date.
- **Selection bias** — portals over-represent some segments; informal and kampung housing barely appear.
- **Location precision** — street, kelurahan or project centroids: check duplicate coordinates and geocode accuracy.
- **Confidentiality** — owner names and phone numbers are personal data (UU 27/2022); client transactions may be under NDA.
