# maps/

Layer definitions, colours, legends and the base-map tile source. Pages import these, so a style change happens in one place.

- Scores use a **sequential** ramp (light = low, dark = high), never a rainbow.
- "No data" is visually distinct from "low": hollow red circle = no asking price; grey = outside 800 m (excluded).
- Every analytical map shows: legend · source & date · CRS · synthetic/real label · scale bar · one-line method note.
