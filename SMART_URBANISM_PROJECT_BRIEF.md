# Smart Urbanism Project Brief

> Example brief for the TOD Opportunity Screener. Replace each answer with your own project's. Start with the urban decision, not the technology.

| Field | Answer |
|---|---|
| **Project name** | TOD Opportunity Screener |
| **Problem** | Sites near stations are shortlisted informally, so good opportunities are missed and choices are hard to justify. |
| **Study area** | One district, with a defined boundary, at property/parcel level |
| **Users** | District planning team (primary); valuers (secondary) |
| **Decision supported** | Which 10–20 properties near stations should go to detailed TOD feasibility? |
| **Data needs** | Parcels or listings, station locations, zoning, flood zones, street network, POIs |
| **MVP features (3–5)** | 1. Map of properties with station catchments · 2. Up to 4 screening criteria · 3. Ranked table · 4. Sources panel |
| **Excluded features (Won't)** | Live data feeds · price prediction · automated zoning interpretation |
| **Expected output** | Map + ranked table + score breakdown + limitations panel |
| **Assumptions** | See `docs/ASSUMPTIONS.md` (e.g. 800 m walking catchment) |
| **Risks** | Data availability and licence; asking prices ≠ values; ranking mistaken for a decision |
| **Success definition** | The planning team uses the shortlist in its next feasibility round and can explain each choice. |

## MVP scope (MoSCoW)
- **Must:** catchments · ≤ 4 criteria · map + table · sources panel
- **Should:** weight sliders · detail pop-up
- **Could:** network walking distance · 3D view
- **Won't:** live feeds · price prediction · zoning AI

## Pitch (60 seconds)
For **a district planning team** in **[district]**, who need to decide **which sites near stations to study further** because **shortlisting is informal and hard to justify**, our tool shows **a map and ranked shortlist with sources** so that **choices are faster, transparent and defensible**.
